FOLIO requires a .env file with your API keys. This file is gitignored and never committed.

Quick setup: cp .env.example .env
Then open .env and fill in:
  • VITE_SUPABASE_ANON_KEY — from your Supabase API settings
  • VITE_AV_KEY — from alphavantage.co (free)

After saving, restart the dev server (`npm run dev`).
